# foil-images

Images des cartes servies à [Foil](https://tcg-card-neon.vercel.app) par GitHub Pages
(`https://hugohnh.github.io/foil-images/ygo/{id}.webp`).

- `ygo/` : cartes Yu-Gi-Oh!, téléchargées une seule fois depuis YGOPRODeck (règle de YGOPRODeck : pas d'affichage
  direct de leurs images) et réduites en WebP de 200 px. Mise à jour chaque semaine (`.github/workflows/ygo.yml`).

Les images des cartes appartiennent à leurs éditeurs (Konami pour Yu-Gi-Oh!).
